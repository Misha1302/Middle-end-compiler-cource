# Занятие 20. Финальный ремонт

> Автономная процедура с готовым банком новых мини-примеров

[← Карта курса](../course-map.md) · [Предыдущее занятие](../modules/19-mock-exam-1.md)

## Результат занятия

Ты закрываешь два первичных пробела и подтверждаешь перенос на незнакомой задаче без зависимости от преподавателя.

**Перед началом:** результаты пробного зачёта.

## Зачем это вообще нужно

Перечитывание правильного ответа создаёт узнавание, но не доказывает навык. Исправление требует уменьшенного примера, точного правила и новой проверочной задачи.

## Термины до заданий

| Термин | Простое объяснение | Точная опора |
|---|---|---|
| **Целенаправленное исправление** (*repair*) | исправляет одну конкретную ошибку | ошибка → нарушенный инвариант → правильное правило → новый пример |
| **Контрпример** | опровергает неверное общее правило | одного корректного контрпримера достаточно для отказа от ложного утверждения |
| **Повторная трасса** | повторяет алгоритм с записью промежуточных состояний | проверяет механику вычисления, а не память конечного ответа |
| **Воспроизведение без подсказки** (*retrieval*) | извлекает знание из памяти без опоры на конспект | показывает, доступен ли навык самостоятельно |
| **Стоп-правило** | задаёт условие завершения исправления | исходная ошибка не повторяется в двух новых примерах подряд |

Сначала прочитай объяснения. Затем закрой таблицу и перескажи термины своими словами. Это проверка понимания, а не попытка угадать определение.

## Ключевая схема

`ошибка → первый нарушенный инвариант → уменьшенный пример → новая трасса → проверочная задача → условие завершения`

## Пошаговый разбор

**Пример ремонта DF:**

1. Ошибка: ученик добавляет точку слияния в `DF(входного блока)`.
2. Нарушенный инвариант: подъём по дереву IDom должен остановиться на непосредственном доминаторе точки слияния.
3. Маленький ромб: вручную поднять узел от обеих ветвей.
4. Новый пример: ромб внутри цикла.
5. Стоп: два графа подряд с правильным DF и формальным свидетелем-предшественником.

## Формальное правило

За одну сессию ремонтируются максимум два пробела. Для определения нужен пример и контрпример; для алгоритма — полная трасса состояния; для преобразования — доказательство допустимости и контрпуть.

## Типичные ошибки

- Ждать, что преподаватель придумает единственный новый пример.
- Решать тот же пример по памяти.
- Исправлять поздний симптом раньше раннего CFG/SSA нарушения.
- Не задавать стоп-правило.

## Задача A — по образцу

Выбери первый пробел и возьми соответствующий автономный пример:

- базовые блоки: `if p goto L; a=1; L: return a`;
- доминирование: ромб с хвостом;
- DF: ромб внутри петли;
- SSA: две ветви и значение, переносимое между итерациями;
- DCE/UCE: постоянное условие и вызов с эффектом;
- циклы: SCC с двумя входами;
- LICM: неизменное деление в условно выполняемом теле.

Запиши ошибку, нарушенный инвариант, исправленное правило и полную попытку.

<summary>Проверка задачи A — открывать после попытки</summary>

Решение зависит от выбранного пробела, но должно содержать четыре явно подписанных части. Отсутствие нового примера означает, что исправление не завершено.

## Самостоятельная задача

Возьми второй пример той же категории из [банка задач на перенос](../practice/transfer-bank.md) и реши без конспекта. Затем проверь стоп-правило.

<details>
<summary>Проверка задачи B — открывать после попытки</summary>

Пробел закрыт, если два новых примера подряд решены без исходной ошибки и ты можешь объяснить правило и один контрпример.

</details>

## Проверь себя

**Как выбрать первый пробел?**  


**Когда остановиться?**  


<details>
<summary>Короткие ответы</summary>

**Почему одного перечитывания недостаточно для исправления?**  
Оно проверяет узнавание, а не самостоятельное применение.

**Как выбрать первый пробел?**  
Найти самое раннее нарушение в цепочке с наибольшим каскадом.

**Когда остановиться?**  
После двух успешно решённых новых задач и точного правила без подсказки.

</details>

## Как это устроено в промышленном компиляторе

После ремонта поддерживай навык коротким воспроизведением без подсказки через 1, 3 и 7 дней, но не повторяй уже устойчивые темы без причины.
