# Пробный зачёт: вариант 2

## Теоретическая часть

1. Чем CFG отличается от дерева доминаторов?
2. Сформулируй определение фронта доминирования через конкретного предшественника.
3. Почему вход φ-функции относится к ребру, а не просто к тексту внутри блока?
4. Когда вызов, который не изменяет память, всё равно нельзя считать чистым?
5. Чем естественный цикл отличается от несводимой сильносвязной компоненты?

## Практическая часть

```text
p = input
n = input
i = 0
s = 0
head:
  if i >= n goto exit
  t = 4 * n + 1
  if p goto use else skip
use:
  idx = 4 * i
  v = load A[idx]
  s = s + v + t
  goto cont
skip:
  dead = t * 0
cont:
  i = i + 1
  goto head
exit:
  print s
```

Построй базовые блоки и CFG, затем вычисли `Dom`, IDom и DF. Переведи программу в SSA, выполни допустимые распространение констант, LVN и DCE, после чего проанализируй цикл. Для LICM и снижения стоимости операций явно перечисли необходимые предпосылки.

<details>
<summary>Ключевые ориентиры</summary>

Для `i` и `s` нужны φ-функции в заголовке цикла. Пока значение `p` неизвестно, обе ветви остаются достижимыми. Вычисление `dead` удаляется DCE. Значение `t` не меняется между итерациями и может быть вынесено, если числовая семантика допускает раннее вычисление. `idx` — производная индуктивная переменная с шагом 4. Загрузку из `A[idx]` вынести нельзя, потому что адрес зависит от номера итерации.

</details>
