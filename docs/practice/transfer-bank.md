# Банк задач на перенос навыка

Эти задачи используют после разбора ошибки. Они не повторяют готовые примеры из занятий дословно.

## Базовые блоки и CFG

1. Разбей `if p goto L1; x=1; goto L2; L1: x=2; L2: return x` на блоки и построй множества предшественников и последователей.
2. Добавь недостижимый блок и объясни, какие результаты анализа должны его игнорировать.
3. Найди ошибку в CFG, где условный переход имеет только одно исходящее ребро.

## Доминирование

1. Для графа `A→B,C; B→D; C→D; D→E,F; E→D` вычисли `Dom`, IDom и DF.
2. Приведи путь, который опровергает ложное утверждение `B dom D`.
3. Объясни, почему заголовок цикла может входить в собственный DF.

## SSA

1. Переведи в SSA ромб с двумя определениями `x` и одним использованием после точки слияния.
2. Переведи в SSA цикл со счётчиком и накопителем; запиши изменение стека версий только для накопителя.
3. Удали одно входящее ребро в блок с φ-функцией и восстанови её контракт.

## Оптимизации без циклов

1. Выполни распространение констант и последующее исправление структуры для условного перехода с заведомо ложным условием.
2. Для разных контрактов эффектов определи, какие операции может удалить DCE.
3. Выполни LVN для двух загрузок, между которыми находится вызов с неизвестными эффектами, и объясни, какие факты о памяти потеряны.

## Циклы

1. Собери естественный цикл с двумя замыкающими блоками.
2. Найди сильносвязную компоненту с двумя внешними входами и докажи, что область несводима.
3. Для `i += 2`, `j = 3*i + 1` выполни снижение стоимости операций.
4. Проверь возможность вынести неизменную загрузку, если внутри цикла есть запись через указатель, который может обозначать тот же адрес.
5. Реши, допустимо ли распределение цикла при межитерационной зависимости с расстоянием 1.
