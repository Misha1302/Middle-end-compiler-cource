# Банк проверочных задач

Эти задачи используют после разбора ошибки. Они не повторяют готовые примеры из занятий дословно и задают достаточно данных для однозначного решения в рамках [контракта учебного IR v1](../ir-contract.md).

Для каждой задачи сохраняй промежуточные состояния, а не только финальный ответ.

## Базовые блоки и CFG

### 1. Ромб с неявным переходом

```text
if p goto L1
x = 1
goto L2
L1:
x = 2
L2:
return x
```

Найди лидеры, построй максимальные блоки, замени fall-through явным `jump`, затем выпиши `pred` и `succ`.

### 2. Недостижимый текст между достижимыми блоками

```text
entry:
goto live
dead:
print 100
return
live:
return
```

Нормализуй CFG, проведи DFS из `entry` и перечисли анализы, которые по умолчанию должны игнорировать `dead`.

### 3. Повреждённый условный переход

Дан фрагмент таблицы:

```text
B0: branch p, B1, B2
succ(B0) = {B1}
pred(B1) = {B0}
pred(B2) = ∅
```

Найди все нарушения контракта и восстанови таблицы.

## Доминирование

### 4. Ромб внутри цикла

CFG:

```text
A→B
B→C,D
C→E
D→E
E→F,G
F→B
G→X
```

Вычисли достижимость, Dom, `idom` и DF для всех вершин. Для каждого ненулевого DF укажи конкретного предшественника-свидетеля.

### 5. Путь-контрпример

Для графа `A→B,C; B→D; C→D` опровергни утверждение `B dom D` одним путём. Затем объясни, почему один путь не может доказать доминирование.

### 6. Собственный фронт заголовка

Для `PRE→H; H→B,EXIT; B→L; L→H` вычисли `DF(H)` по определению через предшественника и отдельно трассой подъёма по `idom`.

## SSA

### 7. Ромб с тремя определениями

```text
x = 0
if p goto T
x = 4
goto J
T:
x = 7
J:
return x
```

Построй SSA двумя отдельными этапами: расстановка φ-функций, затем переименование. Объясни судьбу начального определения `x=0` после DCE.

### 8. Цикл со счётчиком и накопителем

```text
i = 0
s = 0
head:
if i >= n goto exit
s = s + a[i]
goto latch
latch:
i = i + 1
goto head
exit:
return s
```

Запиши полный SSA и отдельно таблицу изменений стека версий только для `s`.

### 9. Удаление предшественника φ-функции

Исходно:

```text
J:
x3 = φ[B1: x1, B2: x2, B3: x3_old]
return x3
```

После доказанного упрощения удаляется ребро `B2→J`. Покажи обязательную последовательность: обновление CFG, входов φ, упрощение однооперандной φ при необходимости и перечень устаревших анализов.

## Оптимизации без циклов

### 10. Постоянное условие и полная очистка

```text
c0 = 3
branch c0 == 4, B1, B2
B1: x1 = 10; jump J
B2: x2 = 20; jump J
J: x3 = φ[B1: x1, B2: x2]; y0 = x3 + 1; return y0
```

Покажи IR после каждого шага: распространение, свёртка, упрощение ветвления, UCE, обновление φ, свёртка и DCE.

### 11. Матрица DCE

Для каждой инструкции укажи, можно ли удалить её при неиспользуемом результате и какие доказательства нужны:

```text
add i32 a, b
sdiv i32 a, b
load p
volatile load p
store p, v
call pure f()
call readonly g()
call unknown h()
```

Используй точную семантику Course IR v1.

### 12. Две загрузки и неизвестный вызов

```text
v1 = load p
call unknown h()
v2 = load p
r = v1 + v2
```

Выполни LVN до вызова и после него. Перечисли факты, которых не хватает для объединения `v1` и `v2`.

### 13. Локальная и глобальная нумерация

```text
B0: t0 = a0 + b0; jump B1
B1: t1 = a0 + b0; return t1
```

Объясни, почему LVN одного блока не имеет права сама заменить `t1` на `t0`. Затем перечисли дополнительные факты для глобального преобразования: доминирование, одинаковая семантика операции и доступность операндов.

## Циклы

### 14. Два замыкающих блока

CFG:

```text
PRE→H
H→A,EXIT
A→B,C
B→H
C→H
```

Проверь доминирование, найди оба обратных ребра и собери естественный цикл для каждого. Реши, совпадают ли множества тел и что потребуется для единственного latch-блока.

### 15. Два ребра или две входные вершины

Сравни:

```text
Граф A: E→H; F→H; H→B; B→H
Граф B: E→H; E→B; H→B; B→H
```

Для каждого найди SCC, внешние входные вершины и реши, доказана ли несводимость.

### 16. Снижение стоимости операций

Для базовой переменной `i(0)=2`, `i_next=i+2` и выражения `j=3*i+1` выведи:

- замкнутую формулу `i(k)`;
- `j(0)`;
- шаг `j`;
- SSA с φ-функцией и обновлением в latch;
- проверку начального случая и одного перехода.

### 17. LICM и возможное совпадение адресов

```text
head:
if i >= n goto exit
v = load p
store q, i
use v
i = i + 1
goto head
```

`p` и `q` определены вне цикла, но анализ псевдонимов ничего о них не знает. Проверь четыре условия LICM для `load p` и укажи первый блокирующий факт.

### 18. Распределение при зависимости расстояния 1

Исходный цикл:

```c
for (i = 1; i < n; ++i) {
    a[i] = f(i);
    c[i] = a[i - 1] + 1;
}
```

Рассмотри две версии:

1. сначала полный цикл записи `a`, затем полный цикл вычисления `c`;
2. сначала полный цикл вычисления `c`, затем полный цикл записи `a`.

Для каждой выпиши производителя, потребителя, расстояние зависимости и вывод о допустимости при отсутствии других эффектов и совпадения массивов.

### 19. Разворачивание с остатком

Разверни в два раза цикл `for (i=0; i<n; ++i) sum += a[i]`. Дай основное тело и обработку остаточной итерации для нечётного `n`. Отдельно проверь порядок загрузок и обновлений `sum`.

### 20. Условная производная индуктивная переменная

```text
head:
if i >= n goto exit
if p goto use else skip
use:
idx = 4*i
v = load A[idx]
skip:
i = i + 1
goto head
```

`p` не меняется в цикле. Реши, при каких условиях можно поддерживать `idx` рекуррентно в каждой итерации, даже когда блок `use` не выполняется. Раздели допустимость дополнительного чистого вычисления и его выгодность.
