# Рубрики проверки

Полные ответы к обычным задачам находятся непосредственно после каждой задачи в раскрывающемся блоке. Здесь собраны общие критерии, чтобы не приходилось искать скрытый «правильный стиль оформления».

## Графовые артефакты

- все вершины и рёбра перечислены;
- `pred/succ` симметричны;
- достижимость считается от entry;
- CFG и dominator tree нарисованы отдельно;
- формальное утверждение подтверждается путём или predecessor-свидетелем.

## SSA

- каждое SSA-имя определяется один раз;
- обычный def доминирует uses;
- у φ один подписанный вход на каждый predecessor;
- placement и renaming показаны как разные фазы;
- после CFG rewrite φ и dominance перепроверены.

## Оптимизации

- до преобразования названы semantics/flags/effect assumptions;
- legality не подменяется ожидаемой выгодой;
- после UCE исправлены predecessors и φ;
- memory facts не переносятся через неизвестный store/call без доказательства;
- сохранена версия IR после каждого pass.

## Циклы

- back edge доказан dominance, а не направлением стрелки;
- natural loop собран обратным обходом без preheader;
- irreducible region подтверждён несколькими внешними входами;
- strength reduction проверена на base case и inductive step;
- LICM имеет отдельные доказательства invariant/effects/speculation/dominance;
- loop transformation сопровождается dependence verdict.

## Шкала

| Уровень | Критерий |
|---|---|
| 0 | ответа или проверяемой попытки нет |
| 1 | назван термин или финал, но нет хода решения |
| 2 | основной алгоритм верен, есть один существенный пропуск |
| 3 | полная трасса и корректные инварианты |
| 4 | дополнительно дан контрпример, transfer и граница применимости |
