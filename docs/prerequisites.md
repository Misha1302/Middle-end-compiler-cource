# Обязательные предпосылки

Здесь собраны понятия, которые нужны в курсе, но не требуют отдельного полного занятия. После каждого раздела есть короткая проверка.

## Привязка имени, хранилище и значение

- **Привязка имени** (*binding*) — связь идентификатора в исходной программе с конкретным объявлением в области видимости. Два одинаковых текста `x` могут ссылаться на разные объявления.
- **Хранилище** (*storage*) — место, где во время выполнения лежат данные: слот локальной переменной, адрес памяти или поле объекта. Содержимое хранилища может меняться.
- **Значение IR** (*IR value*) — результат конкретного вычисления.
- **SSA-значение** (*SSA value*) — значение IR с единственным определением.

Это разные сущности: привязка имени живёт по правилам исходного языка, хранилище — во время выполнения, а SSA-значение — по контракту определений, использований и доминирования в IR.

**Проверка:** параметр `x`, стековый слот для `x` и `%x3 = add ...` — три разных объекта.

## Минимальная семантическая модель

Разрешение имён отвечает на вопрос: «к какому объявлению относится это использование?». Проверка типов определяет, допустима ли операция и какой тип имеет её результат. Анализ эффектов отмечает чтение и изменение памяти, ввод-вывод и возможные исключения.

## DFS и SCC

**DFS — поиск в глубину.** Для каждой вершины он хранит состояние `unvisited / active / finished`, родителя и номер первого посещения. Ребро в активного предка является обратным ребром DFS. Чтобы считать его обратным ребром естественного цикла, дополнительно нужно проверить доминирование.

**SCC — сильносвязная компонента** (*strongly connected component*): максимальное множество вершин, в котором из каждой вершины можно дойти до любой другой. Компонента из нескольких вершин или вершина с ребром в себя указывает на циклическую область, но ещё не гарантирует единый заголовок цикла.

Мини-трасса для `A→B→C→B`: номера DFS — `A=0, B=1, C=2`; сильносвязная компонента — `{B,C}`.

## Рабочая очередь и неподвижная точка

**Рабочая очередь** (*worklist*) хранит объекты, факты о которых нужно пересчитать. Если факт изменился, зависящие от него объекты снова добавляются в очередь. Алгоритм заканчивается, когда очередь пуста и повторное применение функции переноса не меняет состояние.

## Каноническая форма цикла

В обязательных задачах по циклам по умолчанию предполагается:

- заголовок цикла доминирует его тело;
- перед заголовком есть отдельный предвходной блок;
- обратное ребро приходит из замыкающего блока;
- рёбра выхода из цикла подписаны отдельно;
- φ-функция цикла имеет один вход из предвходного блока и один из замыкающего блока.

Если такая форма не дана, сначала явно создай её и исправь φ-функции и CFG.

## Межитерационная зависимость

**Межитерационная зависимость** (*loop-carried dependence*) связывает операцию итерации `i` с операцией другой итерации. Например:

```text
a[i] = a[i-1] + 1
```

Чтение `a[i-1]` зависит от записи предыдущей итерации, поэтому итерации нельзя произвольно переставлять. Расстояние зависимости здесь равно 1. Зависимости внутри одной итерации имеют расстояние 0.

Перед преобразованием цикла выпиши источник значения, его потребителя, направление и расстояние зависимости, а затем проверь, сохраняется ли порядок.
