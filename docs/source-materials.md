# Происхождение материалов

Курс переработан из экзаменационных конспектов в самостоятельный учебный маршрут. Версия 0.2 не сохраняет структуру печатной тетради: определения, модели, worked traces и ответы перемещены перед/рядом с заданиями по педагогическим зависимостям.

Диаграммы и примеры созданы для этого репозитория. Внешние источники перечислены на странице литературы.
