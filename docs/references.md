# Источники и литература

Основные нормативные и первичные материалы, на которые опирается терминология курса:

- Paul Havlak, *Nesting of Reducible and Irreducible Loops*, ACM TOPLAS 19(4), 1997, DOI: [10.1145/262004.262005](https://doi.org/10.1145/262004.262005).
- [LLVM Language Reference: `phi` instruction](https://llvm.org/docs/LangRef.html#phi-instruction) — placement, predecessor inputs and edge-use semantics.
- [LLVM Loop Terminology and Canonical Forms](https://llvm.org/docs/LoopTerminology.html) — header, latch, preheader, dedicated exits and LCSSA.
- Keith Cooper and Linda Torczon, *Engineering a Compiler* — basic blocks, CFG, data-flow analyses and dominance.
- Ron Cytron et al., *Efficiently Computing Static Single Assignment Form and the Control Dependence Graph*, ACM TOPLAS 13(4), 1991.

Курс не требует читать всё заранее. Каждое занятие содержит раздел «Точечное чтение»: прекращайте чтение, когда можете воспроизвести инвариант и решить стандартную задачу.
