# Статус и границы курса

## Что считается готовым

- полный 20-занятийный маршрут по middle-end;
- задания трёх уровней и контрольные работы;
- эталоны и рубрики;
- исполняемый учебный инструментарий для CFG-анализов;
- автоматическая проверка структуры, ссылок и Python-тестов.

## Осознанные ограничения

- Курс не заменяет отдельные курсы по frontend и backend.
- Алгоритм Хавлака разобран на уровне инвариантов, фаз и трассы. Полная production-ready реализация остаётся отдельной лабораторной и должна фиксировать конкретный вариант классификации и структуры данных.
- Основной dependency graph — SSA def-use. Memory SSA, alias analysis, postdominance и полный PDG не реализованы в учебном инструменте.
- Инструмент использует простые алгоритмы, удобные для проверки вручную, а не оптимальные промышленные реализации.

## Ближайшие расширения

1. Лаборатория по построению SSA и verifier.
2. Выход из SSA и liveness.
3. Канонизация циклов: preheader, single latch, dedicated exits, LCSSA.
4. Точная трасса Хавлака на reducible и irreducible CFG.
5. Практический pass manager с invalidation contracts.
