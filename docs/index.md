# Курс по средней части компилятора

Самостоятельный русскоязычный курс по внутренним представлениям и алгоритмам компилятора: базовые блоки, CFG, доминирование, SSA, оптимизации и циклы.

## Что изменено в версии 2

- каждый термин объясняется до первого задания с ним;
- английское название при первом появлении сопровождается русским объяснением;
- каждый алгоритм разобран по промежуточным состояниям;
- ответы к задачам и вопросы для самопроверки находятся рядом с заданиями;
- скрытые предварительные требования вынесены на отдельную страницу;
- учебный инструмент на Python показывает не только результат, но и ход вычисления.

## Область курса

Курс сосредоточен на средней части компилятора. Лексер, парсер, проверка типов и задняя часть компилятора появляются как контекст общей цепочки, но не заменяют отдельные курсы по этим темам.
