# Middle-end Compiler Course

Самостоятельный русскоязычный курс по представлениям и алгоритмам middle-end: basic blocks, CFG, dominance, SSA, оптимизации и циклы.

## Что изменено в версии 2

- термин всегда объясняется до задания;
- английское название при первом появлении получает русскую расшифровку;
- каждый алгоритм имеет состояние-за-состоянием worked trace;
- ответы к A/B и exit-check находятся рядом в раскрывающихся блоках;
- скрытые пререквизиты вынесены на отдельную страницу;
- Python-инструмент умеет показывать не только результат, но и ход вычисления.

## Область курса

Курс сосредоточен на middle-end. Lexer, parser, type checker и backend появляются как контекст pipeline, но не заменяют отдельный курс по frontend/backend.
