# Вклад в курс

Исправления терминологии, контрпримеры, новые тесты и небольшие лабораторные приветствуются.

Перед pull request:

```bash
python scripts/validate_course.py
python -m unittest discover -s tests -v
```

Для содержательного изменения укажите:

- какой инвариант или учебный результат уточняется;
- минимальный пример до/после;
- как проверяется корректность;
- не создаёт ли изменение противоречие с `docs/ir-contract.md`.

Не добавляйте ответы прямо в страницы занятий: эталоны хранятся отдельно в `docs/practice/answers-and-rubrics.md`.
